# Documentation

Welcome to the docs. This is a quantum computing platform made up of several modules, accessible from the tabs above:

| Module | What it's for |
|---|---|
| **[Dashboard](dashboard/index.md)** | Landing page after signing in, quick links to every module plus popular examples |
| **[QCAP](qcap/index.md)** | Structured learning path through quantum computing, organized into modules, live sessions, grades, and a certificate on completion |
| **[Qanvas](qanvas/index.md)** | Freeform, whiteboard-style workspace for combining shapes, files, and quantum building blocks on one canvas |
| **[Qompile](qompile/index.md)** | Browser-based quantum circuit composer - build circuits by drag-and-drop or code, and explore live visualizations |
| **[Sqope](sqope/index.md)** | Feed of quantum computing news, research, and conversations |
