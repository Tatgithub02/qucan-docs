# What is QCAP?

**QCAP** is a structured learning path for quantum computing, delivered as interactive notebooks in a no-setup web environment, part of the [Qucan](../index.md) platform. Instead of a single course, QCAP organizes learning into a sequence of **modules**, each covering one stage of the journey from classical computing history through to real quantum hardware and applications:

`History` · `Foundations` · `Math` · `Core` · `Python` · `Mechanics` · `Protocols` · `Qiskit` · `Algorithms` · `Hardware` · `QEC` · `Applications` · `Future`

Each module is broken into **Parts**, and each Part into individual lessons, videos, readings, reference documents, discussions, and live sessions, so you can progress from fundamentals to advanced algorithms at your own pace, with a persistent cloud workspace and instant feedback along the way.

Beyond the modules themselves, QCAP also gives you **Live Sessions**, **Grades**, **Announcements**, a **Discussions Forum**, **Classmates**, and **Resources**, the surrounding pieces of a full course experience.
