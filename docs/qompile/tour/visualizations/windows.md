# Managing windows

Visualization panels (Probabilities, Q-Sphere, Statevector) can be repositioned and closed via their **⋮** options menu:

- **Move window left / right** - reorder panels within the workspace
- **Close window** - hide the panel (re-enable it later from the [View menu](../customizing.md#view))
