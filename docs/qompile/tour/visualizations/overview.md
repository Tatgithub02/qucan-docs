# Visualizations overview

Qompile includes several live visualization panels that update automatically as you build your circuit:

- [Phase disks](phase-disks.md) - per-gate phase indicators shown directly on the circuit
- [Probabilities](probabilities.md) - bar chart of measurement outcome probabilities
- [Q-Sphere](q-sphere.md) - 3D visualization of the quantum state
- [Statevector](statevector.md) - amplitude bar chart and raw statevector array
- [Managing windows](windows.md) - moving, resizing, and closing these panels

All panels can be toggled on or off from the **View** menu - see [File / Edit / View dropdowns](../customizing.md#view).
