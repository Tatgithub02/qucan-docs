# What is Qanvas?

**Qanvas** is a freeform, whiteboard-style workspace, part of the [Qucan](../index.md) platform. Instead of a fixed circuit diagram or a notebook, Qanvas gives you an open canvas where you can freely place and arrange:

- **Basic shapes and text** - rectangles, circles, triangles, and text labels, for sketching out ideas or annotating a layout
- **Uploaded files** - images, PDFs, Python scripts, and OpenQASM files
- **Quantum building blocks** - an Operations catalog, a Circuit block, a Coding block, and live Bloch sphere, Q-Sphere, and Results panels

Because everything lives on the same canvas, Qanvas is a way to combine circuits, code, visualizations, reference files, and notes side by side, rather than switching between separate tools or tabs.

Each workspace is saved as a file that you can name, save, and download, and it also keeps a library of **ready-made circuits** and **uploaded assets** you can drop onto the canvas at any time.
